# 架构决策记录（ADR）

ADR 用来记录会影响后续设计的选择，而不是记录每个实现细节。每项决策独立编号，编号一旦使用不复用。

## 何时写 ADR

- 有两个以上合理方案，选择会影响后续阶段。
- 需要记录为什么暂时不采用参考项目的复杂设计。
- 模型协议、会话格式、并发、权限或持久化等边界发生改变。

## 固定结构

```text
标题
状态：proposed / accepted / superseded
背景与问题
决定
理由与取舍
影响
关联阶段、契约和代码
```

模板见 [templates/adr.md](../templates/adr.md)。被新决策替代的 ADR 保留原文件，并在状态和新 ADR 链接中说明替代关系。
