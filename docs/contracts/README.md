# 接口与契约文档规范

这里记录跨模块或跨进程可观察的约定。阶段专属、不会复用的局部类型留在阶段文档或代码中，不为了每个函数建立一篇契约。

## 适合建立契约的内容

- `LlmClient` 的请求、响应、错误和取消语义。
- Agent 消息与工具调用/结果的结构。
- 工具注册和执行接口。
- 会话存储的读写、刷新、恢复和所有权规则。
- CLI 的退出码、标准输出和错误输出约定。

## 每篇契约至少包含

```text
名称与状态
目的和边界
调用方 / 实现方
输入字段和约束
成功输出
失败、取消和超时
生命周期与资源所有权
兼容性和版本策略
示例
关联阶段、代码和测试
```

契约状态可以使用 `draft`、`accepted`、`deprecated`。`accepted` 契约的变更必须在阶段文档中说明影响，并在需要时新增 ADR。

阶段模板见 [templates/phase-spec.md](../templates/phase-spec.md)；契约的具体名称按主题命名，例如 `llm-client.md`、`tool-execution.md`、`session-store.md`。
